## 資料模型與不變量

訓練資料是唯讀輸入，模型 JSON 由 `train.py` 產生後就不再修改，HTML 在執行時不保存任何資料。DBR 界線、中位數、切點等參數都由訓練決定，使用者無法更改。

| 欄位 | 型別、格式與可空性 | 預設／約束 | 來源 |
|---|---|---|---|
| `撥貸金額` | 數值，> 0；只在訓練時必填 | 非法的列會被移除 | FR-02 |
| 類別 20 欄 | 0/1；可空、可非數字 | 值等於 1 才算命中 | FR-04 |
| 數值 6 欄 | float；可空 | 空白或非數字轉為 0；無擔保 ≥ 0；DBR 截斷 | FR-04 |
| `行業_未知` 等 4 欄 | 衍生 0/1 | 同組沒有任何欄位命中時為 1 | FR-04 |
| `DBR_為0` | 衍生 0/1 | 原始 DBR == 0 時為 1（在截斷前判斷） | FR-04 |

**特徵順序**（`MODEL_COLS`，共 31 欄）：先是 26 個原始欄（與 CSV 的順序相同），接著是 4 個「_未知」欄，最後是 `DBR_為0`。順序寫在 `M.cols`，JS 依此排列輸入向量。

**`models/hgb.json`**（嵌入成預測工具的 `M`）：

```json
{"base": 3.70, "trees": [{"f": [0,4,-1], "t": [0.5,0.5,0], "l": [1,2,0], "r": [5,3,0], "v": [0,0,-0.14]}],
 "cols": ["行業屬性A", "..."], "dbr": [1.13, 21.98], "median": 40.0, "cut": [28.96, 50.05],
 "log": true, "n": 226578, "trained_at": "2026-11-10 18:52"}
```

不變量：`f[i] = -1` 表示葉節點，此時 `v[i]` 是該棵樹的貢獻值。內部節點滿足 `x[f[i]] <= t[i]` 時走 `l[i]`，否則走 `r[i]`。預測值 = max(0, expm1(base + Σ v))。

**`models/tree.json`**（嵌入成決策樹工具的 `M`）：內部節點的格式為 `{"f": 欄名, "t": 門檻, "l": {...}, "r": {...}}`，葉節點的格式為 `{"n", "med", "mean", "p25", "p75", "hi"}`。所有葉節點的 n 加總等於 `M.n`。

## 介面契約（CLI 與 JS）

本系統沒有 HTTP API（ADR-01），以下 API 編號用來指稱程式介面。

### API-01｜`python src/train.py [--data PATH] [--out DIR] [--skip-ablation]`（FR-09）

預設讀取 `regression8.csv`，輸出到目前目錄。

- 成功：結束碼 0。產出 `models/{hgb,tree}.json`、`reports/metrics.{json,md}`、`dist/撥貸金額預測工具.html`、`dist/撥貸金額(決策樹判斷).html`。
- 門檻未過：結束碼 2。報告照常產出，但 `dist/` 不寫入。
- 欄位缺漏：拋出 `SchemaError("缺少欄位：…")`，結束碼 1，不產生任何成品。

### API-02｜JS `predict(rec) → number`（FR-04、FR-06）

`rec` 是一個物件，欄名對應字串或數字，缺少的欄位視為空。回傳未四捨五入的金額（≥ 0）。這個函式沒有副作用。

### API-03｜JS `batchPredict(text) → {H, rows, res, csv, cnt, mae} | {error}`（FR-10）

- 錯誤只有兩種：`{"error": "檔案沒有資料列。"}`，或 `{"error": "缺少欄位：DBR、…"}`（只檢查 6 個數值欄；類別欄缺少時視為未知）。
- 成功時：`res[i] = [金額(0.1), "低|中|高", "高|低"]`。`csv` 以 BOM 開頭、用 CRLF 分行；含逗號、引號或換行的值會加上雙引號。`mae` 只有在表頭含「撥貸金額」時才有值，否則為 `null`。

### API-04｜其他 JS 純函式

`toFeat(rec)` 回傳含 31 欄的物件；`warnings(rec)` 回傳提示字串陣列；`lvl(a)` 回傳等級；`decode(ArrayBuffer)` 回傳字串（先試 UTF-8 嚴格模式，失敗改用 Big5）；`outName(Date)` 回傳 `預測結果_YYYYMMDD.csv`。決策樹工具另有 `walk(f)` 回傳 `{leaf, path}`，以及 `judge(rec)` 回傳 `{leaf, path, hi}`。在 Node 中執行時，以上函式透過 `module.exports` 匯出；沒有 `document` 時，畫面程式不會執行。

## UI 與模組契約

- **UI-01｜預測工具單筆區**（US-01）：4 個下拉選單（預設「未知／未填」）加 6 個數值欄（預設 0）。「預測」呼叫 API-02；「範例／重設」先填入範例再預測。結果顯示金額、等級標籤、中位數比較與切點；有提示時以橘字顯示。
- **UI-02｜決策樹工具**（US-02）：欄位與 UI-01 相同，標示「★ 決策樹有使用」。結果顯示葉節點統計與判斷路徑；0.5 門檻的類別欄以「是／否」顯示。
- **UI-03｜批次區**（US-03）：檔案選擇後呼叫 `decode` 與 API-03。錯誤以紅字顯示，並隱藏下載按鈕。成功時顯示摘要與前 30 筆（DBR、無擔保總餘額加上 3 個結果欄），下載檔名使用 `outName(new Date())`。
- **文字安全**：使用者 CSV 的內容插入表格前要先做 HTML 跳脫（`esc`），防止惡意 CSV 內容被當成 HTML 執行。
- **`features.py`**：`validate_schema`、`clean_training`、`fit_dbr_bounds`、`make_features`、`level`。這些函式的規則與 JS `toFeat`／`lvl` 必須一致，由 TC-03 核對。
